# Modelos de autorização de uso de imagem

Modelos para o conselho imprimir, preencher e **guardar no arquivo do CMDCA** (nunca no portal). No painel, informe
só a referência (ex.: "Termo 012/2026, pasta Conferência 2026"). Submeta os modelos à Procuradoria antes do primeiro
uso.

Base: Constituição, art. 5º, X; Código Civil, art. 20; ECA, arts. 15 a 18 e 100, parágrafo único, XII (oitiva da
criança e do adolescente); LGPD, arts. 8º e 14 (consentimento específico de pelo menos um dos pais ou responsável
legal).

---

voz dele(a) captadas em:

Evento/atividade: ______________________________________ Data: ___/___/______

1. **Finalidade.** Exclusivamente para divulgar a atividade acima, de forma institucional e informativa, sem fins
   comerciais.
2. **Onde.** ( ) portal oficial do CMDCA ( ) perfis oficiais do CMDCA em redes sociais ( ) material impresso do

3. **Como.** Sem divulgar nome completo, escola, endereço ou qualquer dado que permita localizar a criança ou o
   adolescente. Nenhuma imagem será usada se ele(a) estiver em situação de violência, acolhimento, risco ou se lhe
   for atribuído ato infracional, conforme os arts. 17, 18, 143 e 247 do ECA.
4. **Gratuidade.** A autorização é gratuita.
5. **Prazo.** Válida por ____ meses / até ___/___/______. Depois disso, o conteúdo é retirado ou mantido só como

7. **Dados pessoais.** Os dados deste termo são tratados pelo Município de Pindamonhangaba só para comprovar a
